# 週報產生技能

當使用者要求「產生週報」時，依照以下步驟：

1. 讀取 `logs/` 資料夾中本週的工作紀錄檔。
2. 依「已完成」「進行中」「待處理」三類分別整理。
3. 每項用一句話說明，控制在 300 字以內。
4. 最後輸出成 `reports/週報_日期.md`。

## 輸出格式範例

```markdown
# 週報（YYYY-MM-DD ~ YYYY-MM-DD）

## ✅ 已完成
- （項目）：（一句話說明）

## 🔄 進行中
- （項目）：（目前進度）

## 📌 待處理
- （項目）：（預計時程）
```

## 注意事項

- 若 `logs/` 中沒有本週資料，先詢問使用者要整理哪個時間範圍。
- 保持條列簡潔，避免冗長描述。
